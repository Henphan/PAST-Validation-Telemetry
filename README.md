## Perth Aerospace Student Team
## Project: Telemtry Validation
A project that I will be attempting to complete over 8 weeks as part of the recruitment process.

This project will involve me designing and creating a telemetry validating system. Using C, I will program an STM32 Microcontroller to process telemetry data into packets for transmission.
I will also design and implement a Python program that receives these packets, parse them, and validate its health through built-in metadata.
Finally, these packets will be designed through an interface control document (ICD), where their expected behaviour and architecture are documented. This document will be used to compare the packets behaviour and its expected behaviour during the final tests.
